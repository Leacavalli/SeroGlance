seroGlance

A quick visual look at multiplex serology results, antigen by antigen, straight from SerolyzeR output.

Drop SerolyzeR CSV files here Accepts <plate>_MFI.csv / _RAU / _nMFI per-plate files, merged_<type>…csv tables, or a long table with antigen_label and MFI_Median / RAU / nMFI columns. Add as many files as you like. A metadata CSV (a sample ID column plus variables such as age, sex, site or collection date) is picked up automatically, or add it with Add metadata. Files are read in your browser and never uploaded. seroGlance does not filter your data, so remove low-quality samples and antigens before loading.

Density: each curve is a Gaussian kernel density estimate (Silverman bandwidth) of the values, on the log₁₀ scale when Log is selected, with an area of 1 so groups of different sizes are comparable. The shared x-axis covers the central 99.8% of values; values outside it still count in n, medians and percentages. Hover a panel to read the share of samples below a value; click it for a larger view and a summary table.

Correlations: computed over the samples that have a value for every selected antigen (and a value above 0 on the log scale). Spearman uses ranks, so it is the same on either scale; Pearson uses log₁₀ values on the Log scale. The red line in each scatterplot is a running mean over 30 equal-sized bins of the x values. Samples are matched across antigens by plate and well (or sample name).

Heatmap: one column per sample and one row per antigen, with rows grouped by antigen family (the text before the first “_”). Samples keep the order of the loaded files; nothing is sorted or grouped. Each antigen's values (log₁₀ on the Log scale) are rescaled between its own 1st and 99th percentile, so colours compare samples within an antigen, not antigens with each other. With Fit to width, several samples can share a pixel and their colours are blended; choose 1 or 3 px per sample to see every column.

By group: needs a metadata CSV with one column of sample IDs that match the sample names in the SerolyzeR files (matching ignores case, and SerolyzeR's “.1” suffix on repeated names), plus the variables to compare. Text columns, and number columns with 12 or fewer distinct values, are used as groups directly; other number columns (such as age) are cut into groups at the cut-offs you set; dates are grouped by month or year. Boxes show the median and interquartile range, whiskers reach the furthest value within 1.5 × IQR, and dots are values beyond. With a second variable, boxes are coloured by it; past 8 groups the smallest are combined as Other.

Which wells count: by default only test samples. In SerolyzeR files, names like BLANK, 1/400, S_1/400, EMPTY_H9 and positive/negative control names are treated as blanks, standards, empty wells or controls; a sample_type column is used when present.
